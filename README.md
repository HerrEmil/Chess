# Chess!

A free and open source chess web app built with TypeScript. Play it at [herremil.com/chess](https://herremil.com/chess/) or install it from the [Chrome Web Store](https://chrome.google.com/webstore/detail/hhajejfkogjnnkenablkhgkdmmenbjgh).

## Features

- Local multiplayer
- Singleplayer vs AI with 3 difficulty levels
- Pawn promotion
- Castling
- En passant
- Move highlighting

## Development

### Prerequisites

- [Node.js](https://nodejs.org/)
- [Yarn](https://yarnpkg.com/)

### Setup

```sh
yarn install
```

### Scripts

| Command            | Description                    |
| ------------------ | ------------------------------ |
| `yarn build`       | Compile TypeScript and bundle  |
| `yarn start`       | Build and serve locally        |
| `yarn lint`        | Run ESLint                     |
| `yarn format`      | Format code with Prettier      |
| `yarn format:check`| Check formatting               |
| `yarn test`        | Run tests                      |
